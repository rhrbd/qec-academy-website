The QEC platform plan

One website for the public, one login for everyone inside QEC, and the systems we already run (Master Database, Teacher Portal, Google Classroom, Medha Onneshon) connected behind it.

Timeline

Dates are targets, to be agreed with management.

  1. Oct 2026

    Core systems in place

    Master Database, Teacher Class Portal with live-class rooms, Google Classroom per batch, Medha Onneshon exam site.

  2. Nov 2026

    Website template

    This preview: every public page and every portal screen, with sample content, on GitHub.

  3. Dec 2026

    Launch on qecacademy.com

    Real content, photos and prices. Connect GitHub to Hostinger and point the domain. Admission and contact forms start sending to the database.

  4. Jan–Feb 2027

    One login, live portals

    Student, guardian and teacher pages read from the Master Database. Teacher Portal features move inside the new site.

  5. Mar 2027

    Sales desk and office console

    Every form becomes a lead. Follow-ups, admissions and reports in one place.

  6. 2027 session

    Class 9 and 10

    New programs added to the same catalogue, batches and portals.

  7. Later in 2027

    App on every phone

    The site installs from the browser at no cost. A Play Store version can wrap the same app if needed.

How the pieces fit

The website is the front door. The data stays where it lives today until each part is moved.

People see

  • Public website on qecacademy.com
  • One login page
  • Student and guardian dashboard
  • Teacher portal
  • Sales desk and office console
  • Installable app (same site)

Website connects to

  • A small API layer (Apps Script web app first, a proper backend later)
  • Sign-in with QEC ID and PIN, one role per person
  • Forms that create leads and tickets

Data lives in

  • [CORE] Master Database 2026
  • Teacher Portal class log
  • Google Classroom (6 classrooms)
  • Google Meet and Calendar
  • Medha Onneshon sheets
