How a week at QEC works

The same steps for every batch, online or at the centre.

  1. Enrol

    Choose a class, version and batch. A free trial class comes first if you like.

  2. Get your ID and PIN

    Each student gets a QEC ID. It opens the student dashboard on any phone.

  3. Join live classes

    Classes open from the dashboard. Only students of that batch can enter.

  4. Sit the weekly exam

    Short exams every week, model tests every month, results the same day.

  5. Guardian report

    Attendance and marks reach the guardian, with the teacher's note.
